YIALCO LTD — Digital business card

Files:
- index.html: the responsive digital business card
- elina-ioannou.vcf: contact card downloaded by the Save Contact button

Free hosting suggestion: GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. yialco-digital-card.
3. Upload index.html and elina-ioannou.vcf to the repository root.
4. In Settings > Pages, enable deployment from the main branch and root folder.
5. GitHub will provide a public URL. Test the page and the Save Contact button on a phone.
6. Only after the final URL exists, generate a QR code pointing to that exact URL. Do not use a QR pointing to a temporary preview.

Before publishing, confirm that the company approves public display of these contact details and that the company website link is correct.
